一、核心逻辑

为什么是两存供应链？

  1. 长江存储（YMTC）+ 长鑫存储（CXMT） 是国内存储芯片双雄，正在加速产能扩张
  2. 扩产链条清晰：先建厂房（洁净室）→ 采购设备 → 晶圆制造 → 封测 → 模组出货
  3. 受益确定性高：已明确是两存客户（长江+长鑫双认证）的标的，业绩增长能见度高
  4. 今日市场验证：半导体板块5月20日大爆发，晶方科技、柏诚股份双双涨停

六、产业链受益顺序（由近及远）

两存扩产 → 厂房建设(洁净室) → 设备采购 → 晶圆制造 → 封测 → 存储模组
顺序环节代表标的受益时间点
1电子洁净室柏诚股份、亚翔集成、深桑达A最确定，扩产前必先建厂房
2半导体设备北方华创、中微公司建厂后采购设备
3先进封装晶方科技、长电科技、通富微电产能释放后封测需求增加
4存储模组德明利、江波龙终端需求拉动，最后受益
操作节奏建议：
  1. 现在：布局洁净室（柏诚、亚翔）+ 设备（北方华创、中微）
  2. 1-2个月后：布局封测（晶方、长电、通富）
  3. 3-6个月后：关注存储模组（德明利、江波龙）回调机会

七、风险提示

  1. 两存扩产不及预期：若扩产进度推迟，供应链订单将受影响
  2. 估值过高风险：部分标的年内涨幅过大（德明利+200%、江波龙+133%）
  3. 科创板流动性风险：科创板标的流动性低于主板
  4. 行业周期风险：半导体行业具有周期性
  5. 地缘政治风险：中美科技脱钩可能影响供应链，但也加速国产替代
