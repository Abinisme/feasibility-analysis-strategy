PCB行业产能过剩分析

2026年4月16日 文章来源：虎嗅APP | 作者：张博
分析目标：① 对科技持仓的警示 ② PCB高端产能选股建议

一、文章核心观点摘要

1. 核心结论

  • AI把PCB捧上神坛，但这轮"PCB热"本质是高端产能扩张而非总量扩张
  • 2025-2026年国内头部PCB企业新增高端产能投资计划总额超400亿元
  • 扩产时间高度集中，2026年下半年到2028年是产能集中释放期
  • 核心风险：高端赛道局部过热 + 中端赛道提前承压

3. 关键警示（对比光伏/锂电）

"需求爆发 → 龙头赚钱 → 资本加注 → 企业集体扩产 → 产能释放滞后 → 供需错配 → 价格战 → 利润塌陷"
  • 制造业最危险的错觉：把今天的紧缺直接外推成未来长期稀缺
  • 光伏和锂电的问题从来不是"没有需求"，而是供给扩得比需求兑现更快
  • 真正危险的信号：所有厂商都在扩同几个热门方向（AI服务器板、交换机板、IC载板）

4. 核心判断标准

"市场最终不会奖励'大家都在做的高端'，只会奖励'真正能稳定做出来，并且能持续拿到订单的高端'"

两种路径分化：

  • 路线A（内卷）：简单放大产能，蹭AI热点
  • 路线B（升级）：完成高端工艺突破 + 客户结构升级 + 全球交付能力建设

警示一：沪电股份（朋友持仓）短期过热

  • 4月14日涨停+10%（97.54元），5连涨
  • 当前PE/估值已反映AI红利，高位追入风险大
  • 文章风险释放时间窗口：2026年下半年至2028年
  • 操作建议：朋友持仓的沪电，若成本低可续抱；高位建仓者需警惕

警示二：北方华创（半导体设备）逻辑强化

  • PCB大扩产 → 半导体设备需求上升
  • 北方华创是PCB设备供应商之一（蚀刻机、沉积设备）
  • 属于PCB扩产的上游受益逻辑，而非PCB本身——这是更安全的持仓方向

警示三：避免"光伏式思维"

  • 光伏在2020-2021年也是"需求爆发、高端产能紧缺"
  • 问题是供给曲线比需求曲线更陡
  • PCB现在正在走同一段路，现在入场PCB股票≈2021年追光伏

警示四：立讯精密需关注

立讯有部分通信/消费电子PCB相关业务，属于"蹭热点"还是"真实高端能力"，需要进一步确认。

三、PCB高端产能建仓分析

核心选股标准

  1. 高端工艺壁垒：能否稳定量产高多层板（20层+）、高频高速板
  2. 客户结构：是否切入英伟达、AMD、谷歌、微软等AI基础设施供应链
  3. 产能节奏：扩张节奏是否匹配需求释放窗口（2026-2027年达产）
  4. 全球交付能力：是否有泰国/越南等海外产能规避地缘风险
  5. 财务健康：是否有足够的现金流支撑高端产能建设

最看好的高端产能标的

★ 深南电路（002916）— 首选

理由：

  1. 壁垒最高：A股中高端PCB/IC载板技术最领先，20层+高多层板和IC载板已稳定量产
  2. 客户质量：华为核心供应商，切入AI服务器交换机核心供应链
  3. 国货替代：中美摩擦背景下受益于国产替代大逻辑，外资大厂替代空间大
  4. 产能节奏稳健：不像胜宏、沪电那样激进扩张，财务风险更低
  5. 估值合理：相对沪电PE更低，安全边际更高

AI服务器 + 交换机 + IC载板三线同时受益，国货替代 + 高端化双逻辑护航。

备选：鹏鼎控股（002938）

  • 优势：苹果供应链 + 规模优势 + 泰国产能布局
  • 劣势：消费电子占比仍高，AI绑定程度不如深南和沪电

回避：胜宏科技（300476）

  • 200亿激进扩产，产能过剩风险最高
  • 高度绑定英伟达，单一客户风险集中
  • 当前位置估值已高

四、综合结论

对用户持仓的警示：
  1. 北方华创：利好，半导体设备受益于PCB扩产上游逻辑，可持有
  2. 立讯精密：需确认PCB业务占比和高端能力边界
  3. 沪电/深科技：沪电高位不追，深科技长线逻辑不变
  4. 避免"光伏式思维"：PCB现在≈2021年的光伏，不要在景气最热时追高

若要建仓PCB高端产能

  1. 首选：深南电路（002916） — 壁垒最高、客户最优质、扩产最稳健
  2. 次选：鹏鼎控股（002938） — 苹果供应链稳健，泰国产能布局好
  3. 回避：胜宏科技（300476） — 激进扩产风险，估值偏高
  4. 建仓时机：等这轮调整后（2026年下半年）再大仓位介入
