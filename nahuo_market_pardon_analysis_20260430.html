为什么市场频频"原谅"北方华创？

撰写时间：2026年4月30日

行业背景：半导体设备Q1业绩大爆发

来源：东方财富网《半导体设备Q1业绩扫描：多家龙头净利暴增 AI仍是核心驱动因素》

近日A股一季报已陆续披露完毕，《科创板日报》梳理了市值高于500亿元的8家半导体设备公司，包括北方华创、中微公司、拓荆科技等。整体来看，几家设备厂商业绩呈相对积极之态势——共有5家实现一季度营收、净利同比双增。值得一提的是，中微公司与拓荆科技创下了归母净利润单季度历史新高。

关于营收、净利增长原因，上述半导体设备公司不约而同提到AI硬件需求蓬勃对业绩的推动作用。

  • 中微公司：先进逻辑器件中段关键刻蚀工艺和先进存储器件超高深宽比刻蚀工艺实现量产
  • 拓荆科技：应用于先进制程领域的设备批量获得客户验证通过，量产规模进一步扩大
  • 信达证券：在AI需求加速释放带动下，产业链上下游整体景气度维持在较高水平
  • 国金证券：2026年初国产化率从2024年的15%跃升至35%，刻蚀/薄膜沉积突破40%。中国产设备首次在主流产线承担过半角色

核心问题：看似"暴雷"的财报，为何市场选择原谅？

2026年4月，北方华创（002371.SZ）的年报和一季报接踵而至：

2025年年报：营收393.53亿元，同比+30.85%；净利润55.22亿元，同比-1.77%

2026年Q1：营收103.23亿元，同比+25.80%；净利润16.35亿元，同比+3.42%

表面看，这是一份"增收不增利"的暴雷财报。但市场给出的答案是——原谅。

4月20日至4月30日，北方华创股价从447元暴涨至535元，9个交易日累计涨幅21.61%，其中4月27日更是强势涨停。

这不是散户主导的行情。北方华创是典型的机构重仓股，每日前十大成交中机构席位占比极高，日常换手率极低，日均成交额却动辄70-100亿元——这种成交量级别和换手率特征，本质上是机构在互相换手、筹码在机构间转移。

1.2 关键特征：这不是散户能玩得动的股票

对于一只股价450-530元区间的股票，日均成交额70亿元意味着：按户均500万成交计算，每日约1400个账户在交易——这99%来自机构账户。

  • 4月27日涨停当天：成交额102.78亿元，这种量级的资金博弈不可能是散户行为
  • 4月21日缩量下跌：股价大跌4.43%，但成交量仅16.01万股，机构并未出逃，只是洗盘
  • 4月23-24日连续缩量回调：成交量分别只有9.74万和12.98万股，机构在震荡洗盘、吸收筹码

1.3 机构控盘股的技术特征

  1. 缩量回调时机构不出逃：成交量萎缩至10万股以下，说明机构锁仓
  2. 放量拉升时机构配合：涨停日放量至20万股以上，拉升意愿强烈
  3. 盘中振幅可控：振幅始终在3-5%区间，机构对股价控制力强
  4. 缩量上涨：小幅震荡时成交量萎缩，筹码稳定、抛压轻

净利润下滑的两大原因：

  1. 研发投入激增19亿元 — 最核心因素。现在的"利润牺牲"是为了未来的"市场独占"
  2. 合同负债下降≠订单减少 — 同期营收增长30.85%，说明公司在加速交付，结算周期缩短

2.2 机构视角：为什么看好？

  1. 研发投入是护城河：半导体设备核心竞争力在于技术积累。持续高研发投入 = 护城河加深
  2. 国产替代空间巨大：国产化率从15%到35%只是开始，未来3年要突破60%、70%
  3. AI算力拉动设备需求：3D NAND层数从200层向500层演进，刻蚀设备需求成倍增长

三、行业β行情：半导体设备的黄金时代

3.1 板块整体走强

  • 4月27日：科创50大涨近4%，半导体芯片股走强，帝奥微、欧莱新材等涨停
  • 4月28日：半导体设备ETF广发（562590）冲击3连涨，一周累计上涨7.85%
  • 工信部数据：一季度集成电路产品产量同比增长24.3%

这不是北方华创的个体行情，是整个板块的β行情。

3.2 国产替代不可逆

2026年4月22日，美国众议院通过《MATCH法案》，将芯片封锁升级到立法层面。

"瑞银测算，该法案对ASML收入影响约0-5%，但会刺激中国客户提前采购，长期倒逼国产替代提速。" ——SEMI报告

外部约束越强，国产替代的紧迫性越高。北方华创等国产设备厂商，正在从"替代者"变成"被替代者的竞争对手"。

四、机构为何"原谅"？看懂这个，你就懂了北方华创

4.1 散户看到利润下降，主力看到研发成果

散户的思维：净利润下滑 = 暴雷 = 卖出

主力的思维：研发增长 = 护城河加深 = 加仓

这是认知差，也是收益差的来源。

4.2 散户看到合同负债下降，主力看到交付加速

合同负债减少但营收增长 = 结算周期缩短 = 经营效率提升

4.3 散户纠结季度波动，主力布局年度行情

北方华创的机构持仓周期通常是1-3年。他们看的不是Q1净利润增长3%还是30%，而是3年后国产化率能不能突破60%、公司能不能进入全球前三。季度利润的波动，在3年的投资周期里，只是噪音。

4.4 这是一只"必须拥有"的股票

对于基金产品来说，半导体设备板块必须配置北方华创——它是A股半导体设备龙头、国产替代核心标的、市值够大流动性够好、行业地位无可替代。当所有基金都"必须拥有"这只股票时，它的下跌空间就是有限的。

五、风险提示

  1. 估值风险：当前股价约535元，PE约70-80倍，处于历史高位
  2. 周期风险：半导体行业强周期，景气高点后必然有回调
  3. 竞争风险：国际巨头不会坐视国产崛起，必然会降价或技术封锁
  4. 地缘风险：中美关系如果缓和，国产替代逻辑会弱化

结论

市场频频"原谅"北方华创，不是因为机构盲目乐观，而是因为：

  1. 机构的认知更长远：研发投入是护城河，不是负担
  2. 机构的筹码更稳定：机构控盘股不看短期波动，只看趋势方向
  3. 行业的β在加强：半导体设备板块景气度持续，龙头必然受益
  4. 国产替代的逻辑不可逆：政策+技术+市场三重共振

这不是一篇小作文，这是一只机构重仓股的正常表现。

当你用机构的思维去理解北方华创，你会发现——原谅它，是最理性的选择。
