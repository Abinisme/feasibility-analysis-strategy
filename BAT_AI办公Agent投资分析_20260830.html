⚡ 核心观点速览（原文摘要）

  • 年初至今 Coding 快速驱动 AI 商业化增长（Anthropic 与 OpenAI 目前合计 ARR 预估超 1000 亿美金），但随着编程渗透率提升，市场正寻找下一个潜力场景。
  • AI 办公场景潜力大，有望将 AI 带入大众市场：潜在用户从千万级程序员拓展到 10 亿泛白领人群。据 a16z，今年 2-6 月法律领域 Codex 周活跃企业用户增长 108 倍。
  • 全球大厂积极布局：Anthropic 率先推出 Claude Cowork；7 月 OpenAI 将 Codex 与 ChatGPT 整合；近期 xAI 发布 Grok Bot。
  • 国内大厂战略重视：腾讯 3 月率先发布 WorkBuddy（先发优势，月使用次数超千万）；阿里 整合三个产品推出千问办公；字节 将飞书并入豆包，正式推出"豆包工作"品牌。
  • 投资建议：重点关注互联网大厂——办公 Agent 正走向平台化，互联网厂商是平台经济的赢家；办公 Agent 好用与否与可调用工具强关联，大厂在 IM 等领域优势突出，办公有望成为新一轮 B 端平台级产品及新流量入口。

一、为什么办公 Agent 是继 Coding 后的下一个潜力赛道？

原文三大论点：① 人群广——全球超 10 亿知识工作者，远高于 5000 万左右程序员，乐观情形下可创造万亿美金级市场空间；② BAT 与全球模型厂商齐聚布局；③ AI 从高端市场向大众市场拓展的必经之路——使用电脑办公的泛白领用户都是潜在用户，办公 Agent 延展性强，基础模型能力之外，更重要的是 Harness 层（产品能力）与生态协同（MCP/Skill）。

1.1 全球 10 亿+ 知识工作者，潜在市场空间千亿~万亿美金量级

报告采用两种方法测算市场空间：

方法一：白领人群数量 × 渗透率 × ARPU

  • 假设 1（人群）：据微软 2025 年报告《The golden opportunity for American AI》，全球知识工作者约 10 亿。
  • 假设 2（渗透率）：据 JetBrains 2026 年 1 月调查，Coding 场景程序员渗透率已达 90%；办公任务可验证性、标准化程度弱于编程，渗透将低于程序员。盖洛普调研显示 50% 的人在使用 AI，故以 50% 为基点做敏感性分析。
  • 假设 3（ARPU）：C 端 WorkBuddy、千问办公月费 10-40 美元，TRAE 最高档约 100 美元，Claude/ChatGPT/Kimi 最高档接近 200 美元；B 端席位费更高（WorkBuddy 最低档约 29 美元/月/席位）。假设 ARPU 区间 240-2400 美金/年。
  • 测算结果：渗透率 50%、ARPU 240 美元/年 → 1200 亿美元；渗透率 50%、ARPU 2400 美元/年 → 1.2 万亿美元。整体区间 1080-15600 亿美金。

方法二：劳动力价值替代法

  • 假设 1（白领劳动成本）：据 ILO，2024 年全球劳动收入占 GDP 的 52.4%，约 57.6 万亿美元，平均薪酬约 1.6 万美元/年；据 OECD 工资溢价数据，假设白领平均薪酬为全球平均的 1.35-1.75 倍，取均值 2.5 万美金/年，对应每年约 25 万亿美元白领劳动成本。
  • 假设 2（AI 替代率）：据 ILO，全球 24% 岗位对生成式 AI 有暴露度，3.3% 处最高暴露等级（数据录入、文职、记账、金融文员等白领岗位），该人群占全球白领约 12%。假设 AI 远期可承接白领工作量的 9%/12%/15%/18%。
  • 假设 3（Agent 环节价值占比）：企业仅将部分节约成本用于购买 AI 服务。参照 Palantir 客户模型——每帮客户赚 100 美金可获得 24.8 美金报酬，以 25% 为基点做敏感性分析。
  • 测算结果：整体区间约 3000-13500 亿美元（如替代 12% × 占比 30% → 9000 亿美元）。

1.2 模型能力提升 + token 成本降低 + Harness 提升，办公 Agent 有望加速泛化

报告认为，办公 Agent 的集中爆发是三因素共振的结果，且目前仅是初步爆发，后续有望进一步泛化。

因素一：前沿与第二梯队模型能力持续提升，任务复杂度上限不断抬高

  • 模型整体智能水平快速提升：据 Artificial Analysis，LLM 智能水平指数从 2022 年 11 月 GPT-3.5 Turbo 的 3 分升至目前 Claude Opus 5 的 63 分；模型持续强化理解、推理、工具调用和长链条任务执行能力，Agent 从"问答"走向"执行"。
  • 第二梯队追赶加快：2023-2024 年初 OpenAI/Anthropic 较第二梯队领先约 9-12 个月，2024-2026 年初压缩至 3-6 个月；K3 发布后差距进一步缩至3 个月左右。

因素二：开源 + 降价，提高前沿模型可得性，AI 应用能以更低成本调用更好的模型

  • 开源模型能力逼近闭源：以 Kimi K3（7 月 17 日发布）为分水岭，开源模型第一次以"竞争威胁"身份进入全球 AI 定价叙事，发布即登顶 Code Arena。对 AI 应用而言，开源模型私有化能力强、可微调、不依赖单一服务商，数据和推理成本更受控。
  • 性价比突出：K3 评分接近 GPT 5.6 Sol，但 API 定价仅为其 1/2；DeepSeek V4 Pro 0813、Kimi K3 均在帕累托线上。据 SiliconData，闭源模型综合 token 价格指数约为开源模型的 6 倍。
  • 综合 token 成本下行：据 SiliconData，整体 LLM Token 价格指数今年 6 月以来下降明显；闭源模型综合价格指数自 7 月起陡峭下降。

因素三：Harness 能力持续完善——办公 Agent 的三阶段演进

Skill、MCP 等工具被封装进办公 Agent，降低部署与使用门槛，并可稳定高质量交付。办公 Agent 产品形态的变化是 Harness 能力提升的缩影，正由内容生成工具向复杂任务执行平台演进：

  1. 第一阶段：Copilot 辅助办公——AI 嵌入 Office 等既有软件，执行简单任务，进行内容生成。
  1. 第二阶段：Agent 可自主执行任务——包括拆解任务、调用工具、操作电脑等。2024 年 10 月 Anthropic 推出 Computer Use；2025 年 2 月推出 Claude Code 研究预览（5 月正式发布），率先验证"理解任务—拆解流程—调用工具—验证结果"的完整 Agent 执行框架；此后通过 Skills、Claude for Excel 及 Claude Cowork，将 Coding Agent 积累的任务执行能力扩展至通用办公场景。
  1. 第三阶段：办公 Agent 平台化——2026 年 3 月 OpenClaw 快速普及，用户直观认识到"大模型+Harness"可作为 7×24 小时执行任务的 AI 员工。但 OpenClaw 部署门槛高，腾讯、字节、阿里和百度一方面推出云端托管、本地部署及 IM 接入方案，降低"养虾"门槛；另一方面将 Coding Agent 积累的任务规划、工具调用和结果验证能力扩展至文档、表格、研究及企业工作流。产品形态由单一聊天助手升级为集桌面与云端执行、Skills 生态、即时通信入口及企业权限治理于一体的办公平台。BAT 目前的办公 Agent 均为当时"龙虾"产品的迭代，经技能封装与持续迭代，WorkBuddy 等已实现下载安装即用，以极低门槛面向小白用户。

落地验证：法律领域 Codex 周活跃企业用户 2-6 月增长 108 倍

办公 Agent 已初步在 B 端企业打开，尤其是法律领域。据 a16z，自 2026 年 2 月以来，企业 Codex 周活跃用户在 Legal 增长 108 倍、Sales 增长 41 倍、Recruiting 增长 41 倍、Marketing 增长 26 倍、Healthcare 增长 24 倍、Engineering 增长 5 倍。

1.3 海内外大模型厂商、互联网公司纷纷布局，持续加码

当前办公 Agent 赛道主要玩家包括模型厂商、互联网厂商与传统办公软件厂商三类。海内外共振，用户规模快速增长：国内 WorkBuddy 月访问量从 3 月的 900 万增至 6 月的超 2000 万，居国产办公 Agent 榜首；海外 ChatGPT Work 在 6 月推出并与 Codex 整合，两周周活从 600 万增至 1000 万，8 月已突破 2000 万（据 CNBC）。

（1）模型厂商起步较早

Anthropic 布局最早，2026 年 1 月即推出 Claude Cowork，将 Claude Code 的任务执行框架扩展至非编程工作；OpenAI 于 6 月推出 ChatGPT Work 并与 Codex 合并，两周内周活从 600 万增至 1000 万，目前已超 2000 万。

（2）互联网厂商：组织架构密集调整，资源向办公 Agent 收拢

公司组织与产品动作（2026 年）
腾讯 5 月成立云产品六部，统一负责 CodeBuddy 与 WorkBuddy，团队由十余人扩张至百余人，由腾讯云 CTO 王慧星兼任产品负责人；7 月将 QClaw 相关业务并入同一体系，Miora、Ardot 等 AI 应用集中于 WorkBuddy 体系（保留独立入口）。前期赛马（WorkBuddy/Qclaw/QQ-Bot）→ 以 WorkBuddy 为核心。
阿里 3 月成立 ATH 事业部（通义实验室、MaaS、千问、悟空、AI 创新事业部纳入同一组织）；4 月 CEO 吴泳铭内部信设立集团技术委员会、升级通义大模型事业部；6 月合并通义大模型事业部与未来生活实验室成立 Token Foundry 事业部（CEO 直管）；7 月发布千问办公，整合 QoderWork、悟空、MuleRun。
字节 7 月 30 日飞书产品团队整体并入豆包（赵祺负责）；飞书 GTM 团队与火山引擎整合成立"创造力服务平台"（谭待负责）；8 月 TRAE、扣子团队并入豆包体系，8 月 25 日推出统一办公品牌"豆包工作"。

（3）传统办公软件厂商

依托存量办公入口、文档格式标准和企业客户基础，将 Agent 能力嵌入既有办公流程。

二、互联网公司的竞争优势在哪里？BAT 各家定位有何不同？

相比大模型厂商和传统 SaaS 厂商，互联网公司布局办公 Agent 的三大优势：① 生态优势（独立办公 Agent 平台与原有布局协同）；② 产品力更强（打造平台型产品经验丰富）；③ 支持低门槛切换模型（模型中立性）。

2.0 三大竞争优势

优势一：生态优势——跨产品数据流转与任务串联，短期难以复制

腾讯/阿里/字节自身生态庞大，借助企业微信、钉钉、飞书、腾讯文档、IMA 知识库等高频办公入口，形成"获取信息—执行任务—交付结果—沉淀数据"的完整工作闭环，降低用户迁移和学习成本。例如 WorkBuddy 可读取 TAPD 需求数据生成报告、存入腾讯文档、将会议纪要沉淀为知识资产、再通过企业微信推送进展，全程在统一身份、权限和审计体系下完成。

优势二：产品力更强——用户量头部应用基本集中在大厂

  • 2026 年 6 月，腾讯、阿里、抖音为去重用户量排名前三企业，均超 12 亿人；
  • 近 3 年破圈的 AI 应用依然被互联网厂商占据：头部三家大厂占国内 AI 应用 App 超 80% 流量；截至 26 年 6 月，字节、腾讯、阿里占据 AI 原生 App 前五中的四席。

优势三：模型中立性——支持低门槛切换模型

模型厂商的 Harness 和 Agent 调度架构通常优先服务自有模型；但不同模型在视觉理解、代码、搜索、数据分析和复杂推理等任务及成本上各有优势。用量大的企业会做模型路由，而 C 端用户与非科技型 B 端企业不具备该能力。互联网大厂具备更强的模型中立性——当自有模型无法满足特定任务时，可选择能力更优或成本更低的外部模型。

格局初判（原文）：国内办公 Agent 市场腾讯初步领先，阿里、字节重点发力，三家的产品定位接近、策略略有不同——腾讯靠 WorkBuddy 率先完成产品整合，叠加公众号/腾讯文档/IMA 生态，先发+生态优势明显；阿里以千问办公补齐入口分散、能力割裂的短板，但对千问模型有明显倾斜，模型切换门槛高于腾讯和字节；字节最初双产品并行（豆包面向泛 C 端、Trae Work 面向 B 端和重度用户），8 月 25 日推出统一品牌"豆包工作"，同样对自身模型有明显倾斜。

2.1 腾讯：WorkBuddy 用户量领先，社交生态优势突出，产品力较强

  • 产品表现：WorkBuddy 是目前国内办公 Agent 市场最成熟的产品——2026 年 6 月月访问量达 2,097 万次，位居同类产品榜首，近三个月增速约 150%；应用内置的专家、技能和连接器数量多于同类竞品。
  • 定位：大模型时代的工作入口和组织级生产力平台。个人端以"直接交付结果"为核心目标，通过自主规划、工具调用、本地文件操作和多 Agent 协同覆盖全场景任务；企业端接入腾讯文档、网盘、知识库及企微生态，将分散的个人 Agent 连接为"超级团队"，沉淀企业数字员工资产，实现统一权限、安全与运行管理。
  • 微信生态优势：微信小程序支持云端沙箱与本机远程双模式控制 WorkBuddy——云端模式任务在腾讯云沙箱执行，结果通常 1-3 分钟内回传，适合通勤出差等轻量场景；本机远程模式经加密安全隧道读写本地文件，适合需访问本地资料的长时间复杂任务；电脑端生成的报告/表格/PPT 可一键回传小程序并转发微信好友。企业微信连接超 1400 万家真实企业与组织，是 WorkBuddy ToB 战略的强大入口。

2.2 阿里巴巴：千问办公整合三个 Agent 产品，产品快速迭代中

  • 三产品整合、能力互补：QoderWork 脱胎于 Qoder，将代码 Agent 能力从写代码扩展到办公场景，已形成较成熟的桌面端产品和任务执行能力；悟空 由钉钉团队推出，最初目的是通过 AI 实现对钉钉功能的准确调度，沉淀了钉钉的组织关系、权限和企业应用能力；MuleRun 来自陈宇森（钉钉 CEO、千问办公目前负责人）的创业产品，重点探索专家网络和 Skill 市场。整合后主要沿用 QoderWork 的产品页面和架构。
  • 全栈决心：ATH 体系内底层有通义千问自研模型，中间有阿里云算力与 MaaS 服务，入口有钉钉的存量企业组织，未来有望进一步强化协同效应。
  • 生态底盘：钉钉是国内用户规模最大的企业应用——截至 2024 年底用户数达 8 亿、企业组织数 2600 万、软件付费企业数 19 万家；悟空深度融合后已直接内置超 2000 万企业组织，依托钉钉全面 CLI 化重构的底层架构，可原生调用上千项业务能力。

2.3 字节：飞书/豆包/火山引擎整合剑指 B 端；推出统一品牌"豆包工作"

  • 产品演进：过去两年 TRAE 由 AI 编程工具逐步演进为通用工作 Agent——2024-2025 年从 MarsCode 升级为独立 AI IDE，通过 Agent 2.0 和 TRAE SOLO 强化自主开发及多智能体协作能力；2026 年进一步加入 Skills、Memory 和多端协同，并更名为 TRAE Work，应用场景由 Coding 拓展至产品、分析和设计。8 月 25 日推出统一办公品牌"豆包工作"：TRAE Work、扣子与豆包在工作场景的能力整合；TRAE IDE 及 CLI 作为豆包品牌下的编程产品线持续发展；产品和运营团队向豆包产品负责人赵祺汇报。
  • 战略地位：AI 收入已成为字节整体收入中增速最快的部分——按 2026 年 7 月平均消耗口径推算，大模型业务年化营收运行速率超 40 亿美元；豆包月活达 3.82 亿；飞书近期新签企业客户中超 90% 同步购买飞书 AI 功能模块。
  • 整合逻辑：办公信息流正由"人—平台—人"转向"人—Agent—平台"，平台逐步退居数据、工具与权限底座，Agent 成为核心入口——AI 能力重要性的提升是此次整合由豆包牵头的重要原因。字节的整合目标接近微软"Copilot（应用）+ Azure（云）+ OpenAI（模型）"模式，意图打通"飞书（应用）+ 火山引擎（云）+ 豆包/Seed（模型）"的"模型—云—应用"一体化栈。

三、深度分析：主旨 · 论证逻辑 · 关键论据

解读者视角 · 以下为本页整理者的分析，非原文内容

3.1 文章主旨

这是一篇典型的"赛道切换"叙事研究报告：在 AI Coding 商业化已被充分定价（Anthropic+OpenAI 合计 ARR 预估超 1000 亿美金、编程渗透率接近饱和）之后，报告试图回答"AI 应用的下一个主战场在哪里"，并给出明确答案——办公 Agent（从 Chat 走向 Work）。其真正的落点在于投资建议：办公 Agent 正在从工具走向平台，而平台经济的赢家是互联网大厂，因此 BAT 的战略价值需要被重估。文章同时兼具"空间测算（需求侧）+ 供给侧三因素 + 竞争格局（BAT 对比）"的完整卖方研究框架。

3.2 论证逻辑链拆解

起点（事实）：Coding 驱动本轮 AI 商业化，但渗透率见顶 → 市场需要寻找下一个大规模场景
▼

▼
供给侧（Why Now）：模型能力↑（3 分→63 分）+ token 成本↓（闭源为开源 6 倍价格且快速下降）+ Harness 成熟（Copilot→Agent→平台化三阶段）三因素共振

▼
竞争格局：模型厂商早发但生态单薄；互联网大厂有生态/产品力/模型中立三重优势 → BAT 组织密集调整卡位
▼
结论（投资建议）：办公 Agent 平台化 = 新的 B 端流量入口 → 重点关注互联网大厂（腾讯领先、阿里字节追赶）

这一逻辑链的设计要点在于：用"渗透率天花板"制造紧迫感，用"10 亿人群"打开想象空间，用三因素共振解释时机（Why Now），用高频数据证明拐点已至——四步递进，最终自然导向"买互联网大厂"的结论。

3.4 解读者点评：亮点与可商榷之处

  • 亮点一：双方法测算互相校验。方法一（自上而下订阅口径）与方法二（劳动力价值替代口径）结果区间存在交集（千亿~万亿美金级），降低了单一方法的偏差风险；且方法二借鉴 Palantir 的价值分配比例（约 25%），隐含了"AI 厂商只能拿走替代价值的一部分"这一清醒假设。
  • 亮点二：竞争分析抓住"生态 vs 模型"的轴心。报告将互联网大厂与模型厂商的差异归结为 Harness 生态与模型中立性——模型厂商的 Agent 天然偏自有模型，而大厂可以路由最优模型。这一框架能解释为何 OpenAI/Anthropic 先发，而报告仍更看好 BAT。
  • 亮点三：组织架构是先行指标。报告详细梳理 BAT 三家在 3-8 月的组织整合（腾讯云产品六部、阿里 ATH/Token Foundry、字节飞书/TRAE/扣子并入豆包），把"人事即战略"的观察落到投资判断上——办公 Agent 的优先级提升在组织层面已被验证。
  • 可商榷一：两种测算方法均为乐观估算，且未充分折算国内付费意愿差异。方法一的 ARPU 区间上限（2400 美金/年）取的是 Claude/ChatGPT 顶配套餐价格，而现实中多数用户停留在低档位；渗透率 50% 的基点直接对标盖洛普"使用过 AI"的比例，与"为办公 Agent 付费"仍有距离。更关键的是，报告的 ARPU 假设锚定的是海外订阅价格体系——国内 C 端的付费意愿与付费习惯和海外差异很大：国内用户长期习惯免费互联网产品，为工具类软件订阅付费的比例远低于欧美（视频会员、网盘等少数品类除外），办公 Agent 在国内 C 端的实际付费率与 ARPU 很可能显著低于报告基准；B 端虽有按席位付费的习惯，但国内企业软件预算普遍紧缩、采购决策链长、比价文化重。万亿美金应视为远期理论上限而非可及市场，国内市场的兑现节奏大概率更慢。
  • 可商榷二：对模型厂商的判断偏静态。报告认为模型厂商生态单薄，但 ChatGPT Work 周活破 2000 万的增速（两周 +67%）实际上不弱于 WorkBuddy；且模型厂商若持续开放 MCP/Skill 生态，"生态劣势"可能被弥合。
  • 可商榷三：付费率与盈利模型缺位。报告提及 WorkBuddy"付费用户盈利水平较好"、豆包"付费率较低"，但对办公 Agent 的 C 端付费率、B 端续约率、获客成本等关键运营指标缺乏量化——这恰是判断"平台化叙事"能否兑现的核心变量。
  • 可商榷四：办公 Agent 对 BAT 估值的实际拉动有限。即便办公 Agent 跑通，该项业务在三家的营收与利润盘子中占比极小——腾讯的基本盘是游戏、广告与金融科技，阿里是电商与云，字节是广告与电商，三家本质上仍是传统互联网平台，做的是线上垄断收租的生意（流量分发、交易抽佣、广告变现）。当前市场对三家的定价主要锚定传统主业的现金流与利润增速，办公 Agent 更接近一张"远期期权"而非估值主逻辑：它提供的是战略卡位与叙事弹性，短期难以在财报中兑现，不应高估其对股价的直接驱动。
  • 投资视角小结：该报告的叙事框架完整、数据丰富，适合作为理解"AI 办公 Agent"竞争格局的底稿；但使用时需打两层折扣——其一，市场空间是乐观的敏感性测算而非预测，国内付费意愿与习惯的差异会拖慢兑现节奏；其二，办公 Agent 在 BAT 收入结构中占比极小，三家的估值仍由传统平台主业主导，办公 Agent 是期权而非主菜。建议跟踪月活/付费率/ARPU 的实际爬坡节奏与组织整合的落地进度两大指标，警惕叙事领先于基本面。
