7.4 机构提示：主力资金是"确认信号"不是"预测信号"

  2. 但控制当日涨跌幅后，效应基本消失：
    • 当日跌3-7%的票，主力净买次日反而比净卖差0.23pp
    • 涨跌在±3%以内，差异不到0.05pp
    • 只有当日已大涨的票才有正效应（涨3-7%时+0.82pp；涨超7%时+1.89pp）
  3. 分组统计：
    • 主力净买 + 当日涨过3%：次日 +1.675%，上涨比例56%
    • 主力净买 + 当日基本没涨：次日 +0.020%，上涨比例46%
    • 主力净买 + 当日跌过3%：次日 -0.259%，上涨比例51%
  4. "连续N天净流入"同样无效（次日超额均在0.06pp以内，无单调关系）

⭐ 操作含义：

  • 主力净流入 = “上涨的确认信号”，不是"选股信号"
  • 配合"当日涨过3%"才有效 → 今天的胜宏科技（+9.23%）、德科立（+10.58%）符合条件
  • 要警惕的是"价涨钱走"：华天科技（+2.88%但-13.73亿）符合"当日未涨过3% + 主力净流出" → 次日预期偏负
