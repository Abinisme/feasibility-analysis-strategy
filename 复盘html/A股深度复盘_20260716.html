二、核心新闻与市场热点深度解读

2.1 头条事件：长鑫科技科创板IPO申购（“巨无霸抽血”）

事件：7月16日，国产DRAM存储芯片龙头长鑫科技（688825）正式开启科创板申购。本次IPO拟募集资金295亿元，是2026年A股市场规模最大的IPO，也是科创板史上第二大融资项目（仅次于中芯国际）。

深度分析：

  • 抽血效应显著：295亿级别的募资规模在当前缩量调整的市场环境中，对场内资金形成了明显的虹吸效应。机构为参与打新需要提前腾挪仓位，直接导致科技板块（尤其是存储链）在申购日当天遭遇集中抛售。
  • "利好出尽"逻辑：长鑫科技上市是半导体国产替代的标志性事件，但此前存储板块已经充分炒作。申购日当天反而是"买预期、卖事实"的兑现窗口——兆易创新、澜起科技、长电科技等存储链标的全线暴跌。
  • 中长期影响：长鑫科技上市后将进一步充实A股半导体板块的定价锚，对存储产业链的估值体系产生深远影响。短期抽血后，中长期有利于行业整体估值中枢上移。

2.2 韩国央行加息 + 去杠杆风暴（核心外部冲击）

事件：7月16日，韩国央行宣布将7天期回购利率从2.50%上调至2.75%，七名委员一致投票支持加息25基点——这是韩国央行2023年1月以来首次加息，标志着新一轮紧缩周期开启。

连锁反应：

  • KOSPI指数开盘即跌4.4%，盘中跌幅扩大至7%，触发年内第八次全市场熔断。
  • 韩国金融服务委员会（FSC）同日宣布针对单一股票杠杆ETF的监管措施：暂停新产品上市、禁止广告宣传、保证金门槛从1000万韩元提高至3000万韩元。
  • 截至7月13日，韩国全市场超120万个杠杆散户账户触及保证金追缴线，约32-36万个账户已被全额强制平仓。

深度分析：详见第三章。

2.3 霍尔木兹海峡地缘风险升温

中东局势持续升级，WTI原油和布伦特原油价格一度大涨超5%。能源供应链风险骤升，对全球风险偏好形成压制。对高度依赖能源进口的韩国经济构成直接冲击，也影响全球资金的风险偏好。

2.4 全球半导体景气度：分歧加大

  • 利好面：WSTS预测2026年全球半导体市场规模达1.51万亿美元（+89.9%），韩国央行报告指出全球半导体仍存在15%供需缺口。
  • 利空面：AI资本支出可持续性受到质疑，北美云厂商2026年资本开支上限7,250亿美元是否可持续存疑。存储芯片涨价预期开始分化。
  • 关键矛盾：产业基本面（缺货、涨价）与资本市场（去杠杆、获利了结）之间出现明显背离。

2.5 其他值得关注的新闻

三、韩股熔断与全球去杠杆化浪潮

3.1 事件全貌

7月16日是韩国股市2026年以来第8次触发全市场熔断，也是本周内的第二次熔断（7月13日周一暴跌8.95%触发第7次熔断，7月15日暴涨7%触发向上熔断，7月16日再度暴跌触发向下熔断）。三天之内经历"暴跌熔断→暴涨熔断→暴跌熔断"的极端行情。

3.2 核心驱动逻辑

第一层：加息触发

  • 韩国央行加息25bp至2.75%，正式开启紧缩周期
  • AI热潮推高通胀粘性，韩国6月CPI同比3.8%（高于2%目标）
  • 加息直接提升无风险利率，压缩科技股估值

第二层：杠杆ETF的负向螺旋

  • 三星电子+SK海力士合计占KOSPI权重超50%
  • 韩国散户大量买入这两只股票的杠杆ETF产品
  • 股价下跌 → 杠杆ETF被动平仓 → 股价进一步下跌 → 更多杠杆ETF触及强平线
  • 形成经典的"去杠杆踩踏"循环，与2015年A股去杠杆如出一辙

第三层：监管介入的"止血"与"放血"

  • FSC暂停新杠杆产品上市、提高保证金门槛 → 短期"止血"
  • 但同时也意味着现有杠杆头寸的强制出清压力加大 → “放血”
  • 120万散户账户触及保证金追缴线，32-36万账户本金清零

第四层：东亚芯片指数的全球配置冲击

  • 韩国是全球存储芯片（DRAM/NAND）的核心供应国
  • SK海力士单日跌12%+、三星电子跌8%+，直接冲击MSCI亚太半导体指数
  • 全球被动型基金（追踪MSCI/FTSE等指数）被迫减持东亚半导体权重
  • 外资对东亚科技板块的配置信心受到严重动摇

5.4 分板块深度分析

(1) 光通讯 / CPO / 光芯片

行情特征：相对抗跌，光通信-3.32%、CPO-3.12%、光芯片-3.26%，均好于半导体板块的-5.63%。

背后逻辑：

  • 基本面支撑强：北美云厂商资本开支上限7,250亿美元，1.6T光模块升级周期确定性高
  • 中际旭创（-4.82%）：仍为A股成交额之王（344.74亿），但资金净流出34.74亿居全市场第一，说明多空博弈极其激烈
  • 新易盛（-2.41%）：相对最抗跌的光模块龙头，5日跌幅仅0.53%，20日跌幅仅2.74%，下方支撑较强
  • 关键信号：光芯片板块年初至今仍涨72.22%，是整个科技板块中年内涨幅最高的细分赛道

持续性评估：⭐⭐⭐⭐（高）

  • 1.6T升级周期2026-2027年为交付高峰期，业绩确定性高
  • 但短期估值压力大（光通信PE 109.78），需要中报业绩验证

(2) PCB

行情特征：PCB概念-3.03%，相对抗跌。沪电股份仅微跌0.37%，景旺电子逆势涨停（主力净流入9.59亿）。

背后逻辑：

  • 高端PCB持续放量：AI服务器用高多层板、HDI需求旺盛
  • 结构分化显著：PCB板块内部出现明显分化——沪电股份（AI服务器PCB龙头）几乎平盘，而偏消费电子的PCB标的跌幅较大
  • 景旺电子涨停：通信ETF华夏持仓股，受益于5G+AI双驱动

持续性评估：⭐⭐⭐⭐（高）

  • PCB是AI算力基础设施的"铲子股"，受益确定性不亚于光模块
  • 但需警惕20日跌幅已达-21.92%，短期超跌反弹后或进入震荡整理

(3) 存储 / 封测

行情特征：存储器-5.20%，为今日跌幅最大的科技细分板块之一。兆易创新跌停（-10.00%）、澜起科技暴跌-16.44%、长电科技跌停（-10.00%）。

背后逻辑：

  • 长鑫科技IPO抽血：存储链是IPO最直接关联板块，资金为参与打新集中撤离
  • 韩股存储双雄暴跌传导：SK海力士-12%、三星电子-8%+，直接压制A股存储估值
  • 杠杆踩踏：存储板块前期涨幅巨大（兆易创新年初至今+141%、佰维存储+162%），获利盘集中涌出
  • 佰维存储相对抗跌（-1.36%）：前几日已大幅杀跌（5日-28.32%），今日有资金逢低承接

持续性评估：⭐⭐⭐（中等偏高）

  • 存储涨价周期仍在延续（力积电代工报价上调45%），基本面未逆转
  • 但短期筹码结构严重恶化，需要时间消化
  • 长鑫科技上市后，存储链估值体系将重塑

(4) 半导体设备 / 材料

行情特征：半导体设备-4.69%，量比仅0.75（缩量下跌）。

背后逻辑：

  • 北方华创-5.37%：5日跌幅达-20.00%，已进入超跌区间
  • 设备板块估值压力大：PE(TTM)高达162.14，是全市场最贵的细分板块之一
  • 国产替代逻辑未变：华为"韬定律"V2版验证了非EUV路径，中长期利好国产设备链
  • 缩量下跌说明卖压在衰减：量比0.75意味着成交量小于前5日均量，恐慌性抛售接近尾声

持续性评估：⭐⭐⭐⭐（高）

  • 半导体设备是国产替代最核心的"卡脖子"环节
  • 短期超跌后（5日-15.68%），技术性反弹需求强烈
  • 中报业绩有望验证订单高增长

(5) 芯片设计

持续性评估：⭐⭐⭐（中等）

  • 芯片设计板块标的众多，分化将加剧
