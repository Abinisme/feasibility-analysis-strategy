### ⭐⭐ 风险回报率方法论（2026-09 连续7日验证，已固化）
**核心公式**：`风险回报比 = 静态数字 × 资金/情绪方向系数`
- **三个失真**：①用MA5作上行目标（下跌趋势中MA5下移→系统性高估）；②用今日最低作下行支撑（"收=最低"日→系统性低估）；③**崩塌/暴跌日后"数字最好"的往往是"最弱"的**（"离MA5最远"="跌得最惨"）
- **正确用法**：①只在同一趋势状态内比较；②必须叠加"资金方向（放量/缩量）+ RSI5位置 + 板块地位"；③**"数字最差但已到关键支撑 + RSI5极值 + 板块有催化" = 真正机会**
- **实证**：9/18-9/29连续7日呈"数字与质量反向"；9/29数字最好的中际(4.75:1)/新易盛(4.28:1)仍跌，数字最差的天孚(0.50:1)反弹+4.57%最强

### ⭐ 情绪周期应用（连板网口径，已二次验证）
- **冰点期（温度<10°）第1天**：65次同景，50%次日上涨、**温度平均+23°**、最可能"转修复期47%" → **抄底信号**（9/28→9/29实证：温度5°→42°，+37°）
- **修复期第1天**：86次同景，52%次日上涨、**温度平均-1°**、最可能"转退潮期27%" → **不追高信号**
- **"趋势反转"需三条同时满足：放量 + 收复MA5 + 主线放量确认**
- **"RSI5极值是必要条件非充分条件"**：9/29天孚(RSI5=0)反弹+4.57%，北方华创(RSI5=0)仍跌-0.78% → 需叠加"板块属性+资金选择"
